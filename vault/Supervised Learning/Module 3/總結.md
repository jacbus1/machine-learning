4. 三種數學的真正用途

Linear Algebra：把大量 observations 與 features 裝進 matrix，批量計算 Xβ。

Calculus：計算 loss 的斜率，告訴 optimization 應把 parameter 往哪邊調。

Probability：表達不確定性，例如 fraud probability、likelihood 與 class distribution。

y = Xβ + ε

Matrix 是把很多條 y = β₀ + β₁x₁ + … 一次過寫完。

5. Simple 與 Multiple Linear Regression

ŷ = β₀ + β₁x

例如 Salary = 30,000 + 5,000 × Experience。

若 Experience = 4，預測薪金就是 30,000 + 5,000(4) = 50,000。β₀ 是起點；β₁ 是 x 增加一單位時，ŷ 預期改變多少。

ŷ = β₀ + β₁x₁ + β₂x₂ + … + βₚxₚ

Multiple regression 同時考慮多個 features。

Coefficient 的精確解讀

在其他 variables 不變時，xⱼ 增加一單位，預測 y 改變 βⱼ。這正是 Linear Regression 高 interpretability 的來源。

6. Residual 與 Least Squares

圖 2｜紅色垂直距離就是 residual：e = y − ŷ。

eᵢ = yᵢ − ŷᵢ

Actual − Prediction。

如果一個 error 是 +10，另一個是 −10，直接相加會變成 0，令錯誤互相抵消。因此 least squares 把每個 residual 平方後再加總。

RSS = Σ(yᵢ − ŷᵢ)²

OLS 找令 RSS 最小的 coefficients。

7. OLS 的 Matrix 版本

β̂ = (XᵀX)⁻¹Xᵀy

Xᵀ 是 transpose；inverse 與 multiplication 令很多 observations 可一次過計算。

X：n × p 的 feature matrix；n 是 observations，p 是 features。

Xᵀ：把 rows 與 columns 對調，讓 dimensions 可配合後續 multiplication。

β̂：模型由資料估計出來的 coefficients。

限制：若 XᵀX 不可逆或 multicollinearity 嚴重，實務上通常用數值方法、QR/SVD 或 regularization。

8. Regression Metrics

圖 3｜MSE、RMSE 與 R² 回答不同問題。

MSE = (1/n) Σ(yᵢ − ŷᵢ)²

平均平方誤差；越小越好，但單位被平方。

RMSE = √MSE

單位回到 y 的原本單位，例如房價誤差約 $42,000。

R² = 1 − SSres / SStot

比較模型與『全部猜平均數』；不是 accuracy。

常見誤解

R² = 0.80 可粗略說模型解釋約 80% outcome variation，但不代表每一筆 prediction 有 80% 準確率。

11. Logistic Regression

z = β₀ + β₁x₁ + … + βₚxₚ

先用 coefficients 計算線性 score。

p = 1 / (1 + e⁻ᶻ)

Sigmoid 把任何 z 壓到 0 與 1 之間。

圖 6｜threshold = 0.5 時，p ≥ 0.5 分為 Positive。

Logistic Regression 的名字有 Regression，但主要用途是 classification。它的 coefficient 可解讀 feature 對 log-odds 的影響，也可轉成 odds ratio。

為甚麼需要 log 與 cross-entropy？

Likelihood 會把很多 probabilities 相乘；log 利用 log(ab)=log(a)+log(b) 把 multiplication 變成 addition，方便數值計算與 optimization。

Loss = −[y log(p) + (1−y) log(1−p)]

答對且有信心 → loss 小；答錯而又過度自信 → loss 非常大。

14. SVM 與 Kernel

Margin：decision boundary 與兩類最近 points 之間的安全距離；SVM 希望 margin 最大。

Support vectors：最接近 boundary、真正支撐其位置的 observations。

Linear kernel：用直線／hyperplane 分類，較簡單、較易解釋。

Polynomial kernel：捕捉 x、x²、x³ 等曲線結構。

RBF kernel：用局部距離產生彈性很高的 nonlinear boundary；需特別注意 scaling 與 overfit。

16. L2 Regularization

Regularized Loss = Original Loss + λ Σβⱼ²

一邊 fit data，一邊不讓 coefficients 變得太極端。

圖 9｜λ 增加時 coefficients shrink；variance 通常下降，但太大會 underfit。

λ = 0：沒有 regularization，模型較自由。

λ 增加：large coefficients 受更大懲罰，complexity 與 variance 下降。

λ 太大：coefficients 接近 0，signal 也被壓掉，形成 underfit。

完整鏈條

coefficient → complexity → overfit/underfit → cross-validation 選 λ。

18. Cross-validation

圖 10｜每個 fold 輪流做 validation；其餘 folds 用來 training。

CV score = (score₁ + … + scoreₖ) / k

比單次 train/validation split 更穩定地估計 hyperparameter 表現。

CV 不是 final test

Training data 內用 CV 選 hyperparameters；選完後才用 untouched test set 做最後一次 unbiased evaluation。反覆看 test set，test 就變相參與 tuning。

20. Accuracy：imbalanced data 的陷阱

Accuracy = (TP + TN) / (TP + FP + FN + TN)

所有 predictions 中有多少正確。

假設 10,000 筆交易只有 100 筆 fraud。模型永遠說 Normal，也有 99% accuracy，卻一宗 fraud 都捉不到。因此 fraud detection 不可只看 accuracy。

檢查方法

先看 class balance；再看 confusion matrix、recall、precision、F1、PR curve／ROC-AUC，以及實際 dollar cost。

21. Precision、Recall、F1

圖 12｜Precision 問『我捉得準不準』；Recall 問『真正 fraud 我捉得齊不齊』。

Precision = TP / (TP + FP)

所有被 flag 的 cases 中，有多少真的 Positive。

Recall = TP / (TP + FN)

所有真正 Positive 中，有多少被模型捉到。

F1 = 2 × Precision × Recall / (Precision + Recall)

Harmonic mean；任一邊很低，F1 都不會漂亮。

Business priority

23. ROC Curve 與 AUC

圖 13｜ROC 的 Y 軸是 TPR/Recall；X 軸是 FPR。曲線越靠左上角越好。

FPR = FP / (FP + TN)

正常樣本中，被錯判為 Positive 的比例。

AUC 可理解為：隨機抽一個 Positive 與一個 Negative，模型把 Positive 排在 Negative 前面的機率。AUC = 0.90 代表強 ranking ability，但不是 accuracy = 90%。

AUC ≈ 0.5：與 random guess 差不多。

AUC = 1：完美 ranking。

注意：高度 imbalanced case 亦應查看 Precision–Recall curve，因為大量 TN 可令 ROC 看起來較樂觀。
